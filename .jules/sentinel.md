## 2024-05-18 - [Information Disclosure] Fix Information Disclosure in User Handlers
**Vulnerability:** Internal server errors (HTTP 500) were directly returning the `err.Error()` string in Gin handlers (e.g., in `CreateUserHandler` during password hashing and database insertion failures), which can expose internal stack traces, system paths, or database schema details to users.
**Learning:** Returning raw error details to the client is a common anti-pattern that can aid attackers in mapping out the system or crafting targeted exploits. Gin's `c.JSON` was used to return the error message directly without intermediate logging or filtering.
**Prevention:** Always log the detailed error internally using `c.Error(err)` for debugging purposes, and return a generic error message like `"Internal server error"` to the client when handling HTTP 500 responses. Ensure `return` is called immediately after to halt further execution.
